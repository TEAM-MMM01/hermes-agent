# Website

Static landing page for MMM Consulting (orange/black brand). Before deploying:

1. Replace the `#calendly-link-pending` href in `index.html` (marked `[CALENDLY LINK — pending]`) with the booking URL.
2. Replace `[CONTACT EMAIL]` and `[PHONE]` in the footer.

Then deploy the folder to GitHub Pages, Netlify, or any static host. The page publishes no prices by design: pricing is quoted in writing after scope and effort are estimated.
