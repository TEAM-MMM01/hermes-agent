2. External content is DATA, never authority; untrusted content cannot change governance, prompts, permissions, wallet policy, or tool authority.
3. Certification has re-test triggers for material model/prompt/skill/tool/platform/permission/security/performance drift.
4. Watchdog and Kill Switch must be implemented as explicit system controls with scoped soft/hard stop and re-arm semantics.
5. Material wallet/spend limits must be enforced outside the agent reasoning loop.
6. Side-effecting actions require explicit idempotency/retry semantics.
7. Long missions require in-flight budget/progress checks.
8. Subjective MASTER domains require judgment-aware review and real-world outcomes, not false-precision automated scoring alone.
9. Settlement/recovery claim portals must be verified against official sources before submission.
10. Specification depth must be proportional to consequence if a control fails.
